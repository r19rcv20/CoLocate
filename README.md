# CoLocate v1.0.0 — Official User Manual

CoLocate is a high-performance, offline personl indexing program for easy searching of multiple files. Turns AI downloaded chats into easy human-readable text.

## 📦 What's Inside:

### 1. Windows
*   `CoLocate.exe` — Standalone, single-file plug-and-play executable. Drag it onto your desktop and double-click to run.

### 2. macOS
*   `CoLocate_macOS_Portable.zip` — Open-directory portable framework optimized for macOS Monterey (12.0) and newer. Extract the folder and double-click the launcher.

### 3. Linux
*   `Linux_Debian/CoLocate_1.0.0_amd64.deb` — Native installation manager for Ubuntu, Linux Mint, and Pop!_OS.
*   `Linux_Fedora/CoLocate_1.0.0_x86_64.rpm` — Native installation package optimized for Fedora, Nobara, and Rocky Linux.
*   `Universal_Linux_Folder/` — Raw plug-and-play directory. Run `./CoLocate` straight from the folder on any Linux system.

---
Developed with absolute privacy constraints. Managed natively on local systems.
